# Review Writing Academy question standards

**Easy to understand. Challenging to complete.** Apply these checks to every R2 curriculum change before review.

| Check | Acceptance standard |
| --- | --- |
| Instructions and English | Name the task in a short, direct instruction. Use natural, age-appropriate English and introduce specialist terms where they help students understand the writing. Put the source and question in distinct sections when learners need to refer back. |
| Context | Give the purpose, intended reader and all facts needed to judge the answer. Include any earlier paragraph on which a question depends. State time, cost, access and audience constraints when they affect the verdict. |
| Answer and distractors | Solve a copy with the key and feedback hidden. Try to defend every distractor using only the supplied evidence. Rewrite the task if two choices are defensible. Alternatives should be plausible, natural, distinct and similar in length and specificity. |
| Feedback | Explain why the chosen answer works and name the exact fact or relationship each distractor overlooks. Use evidence from the task and distinguish incomplete support from factual error. |
| Progression | Discover introduces the principle. Explore shows it working in a model. Bronze checks recognition, Silver asks learners to compare and apply, Gold asks them to write or revise, and Master tests transfer with less scaffolding. |
| Writing and interactions | Keep authentic writing for open decisions. Use checked selection for a well-defined answer, matching for relationships and clear keyboard-operable layouts for ordering and grouped plans. Provide a useful model and checklist for self-review. |
| Evidence of learning | Treat minimum-length text as an attempt. Distinguish independently correct, correct after feedback, supported completion, self-review and teacher assessment. Tick-box completion does not validate writing quality. |
| Versions and progress | Keep stable IDs when meaning stays the same. Version substantive edits and give changed options new identities. Preserve unchanged answers, drafts and checks. Test old saved state, resume and student-pilot isolation before merging. |
| Cambridge 0511 | Align with the actual brief, audience, purpose and expected register. Paper 1 Exercise 6 can be a review, with 120–160 words and up to six marks for content and nine for language. Mark Academy models as practice. Present timers, titles and planning structures in their relevant context. |
