## diag-candidate-002 — quiet

**Observed issue:** Three obviously noisy distractors (loud music, cheering, shouting) allow elimination without close discrimination.

**Proposed stem:** The teacher asks everyone to work quietly. Which student follows the instruction?

| Option | Proposed text | Key |
|---|---|---|
| A | Ben reads his book without speaking. | ✓ |
| B | Ben reads his book aloud to his friend. | |
| C | Ben asks his friend a question in a normal voice. | |
| D | Ben talks to his friend while reading. | |

**Reviewer note:** All options concern the same activity. The contrast depends on the manner of reading or speaking, not an obviously unrelated scenario. Check that “without speaking” does not make the answer too transparent for A1.

## diag-candidate-005 — carry

**Observed issue:** Correct option is the only one that explicitly repeats “upstairs” from the stem; two distractors fail to complete the trip.

**Proposed stem:** Sam needs to carry a box from the classroom to the office. What does he do?

| Option | Proposed text | Key |
|---|---|---|
| A | He pushes the box along the floor to the office. | |
| B | He lifts the box and walks with it to the office. | ✓ |
| C | He pulls the box on a trolley to the office. | |
| D | He rolls the box along the floor to the office. | |

**Reviewer note:** All four reach the destination. The target is *carry* rather than *move*. Consider whether “lifts” is too strong a synonym clue.

## diag-candidate-051 — near

**Observed issue:** Incorrect answers mention another city, several hours and another country, making them implausibly distant.

**Proposed stem:** Which sentence means that the library is near the school?

| Option | Proposed text | Key |
|---|---|---|
| A | It is a short walk from the school. | ✓ |
| B | It is a short drive from the school. | |
| C | It is two bus stops from the school. | |
| D | It is on the other side of the town. | |

**Reviewer note:** **Do not approve this version yet.** “Short drive” and “two bus stops” could also be near. This illustrates the essential requirement: exactly one defensible answer, not merely similar-looking distractors. Re-author with an unambiguous context before using.

## Review protocol

1. Verify a single defensible key without using rationales.
2. Ask whether a student can guess through option length, obvious opposites, stem repetition or unrelated distractors.
3. Confirm that the question measures the intended vocabulary sense rather than background knowledge or general logic.
4. Have a second reviewer independently check CEFR hypothesis and ambiguity.
5. Pilot and calibrate before treating a proposed CEFR label as measured proficiency.

**Do not bulk-replace the production bank with these drafts.** They are deliberately held for editorial review.
