# Diagnostic reconstruction — batch 01 (8 high-priority items)

**Status: editorial candidates, not approved.** No production database mutation. Keep original item IDs for tracking, but any accepted replacement must be versioned and independently reviewed. Provisional CEFR levels are *hypotheses*, not certified scores.

This batch deliberately moves away from the original repeated pattern of “Which description matches [target]?” with three absurdly wrong descriptions. It uses short natural contexts, parallel answer options, and checks for defensible alternatives. Some are still easy; pilot response data is needed to establish discrimination.

## A1 — 003 choose

**Stem:** The school offers art, chess and football clubs. Nina likes all three, but she can join only one. What must she do first?

| ID | Option |
|---|---|
| A | Find out what the clubs are called. |
| **B (key)** | Decide which club she wants to join. |
| C | Ask whether all three clubs are popular. |
| D | Find out how many students attend each club. |

**Concern:** B is the only action that solves the problem; still vulnerable to general reasoning rather than lexical understanding. **Hold for redesign** into a contextual lexical-use item if independent reviewers find it too transparent.

## A1 — 004 price

**Stem:** “The tickets were £8 last week, but they are £10 now.” What has changed?

| ID | Option |
|---|---|
| A | The number of tickets. |
| B | The date of the show. |
| C | The place to buy tickets. |
| **D (key)** | The price of the tickets. |

**Concern:** Key contains the target and monetary cue; this is an easy anchor, not a strong discriminator. **Hold for redesign**; do not approve just because it is unambiguous.

## A2 — 015 invite

**Stem:** Which message asks a parent to attend the school information evening?

| ID | Option |
|---|---|
| A | “We appreciated seeing you at the information evening.” |
| B | “The information evening has moved from Tuesday to Thursday.” |
| **C (key)** | “We would be pleased if you could join us on Thursday.” |
| D | “The information evening will finish at half past seven.” |

**Improvement:** Target word *invite* no longer appears in the keyed option; all choices are complete messages. **Remaining risk:** the stem says “asks ... to attend,” a strong paraphrase clue. Reviewer must determine whether it assesses A2 invitation language or simple speech-act recognition.

## A2 — 018 remind

**Stem:** The class often forgets to bring its reading books. Which message is a reminder?

| ID | Option |
|---|---|
| A | “I lent you my reading book last Thursday.” |
| B | “I bought a new reading book yesterday.” |
| C | “I will lend you a reading book tomorrow.” |
| **D (key)** | “Remember to bring your reading book tomorrow.” |

**Improvement:** Assesses lexical function rather than the grammar of *remind someone to*. **Remaining risk:** the keyed *Remember* is a transparent cognate-like clue; likely easy. Review as an anchor only, or redesign.

## B1 — 022 consequence

**Stem:** A school shortened lunch breaks. Which sentence describes a possible consequence?

| ID | Option |
|---|---|
| A | “The school had discussed shorter lunches for months.” |
| B | “Several students had requested longer lunches.” |
| C | “The headteacher explained the decision in assembly.” |
| **D (key)** | “Fewer students had time to attend lunchtime clubs.” |

**Improvement:** Removes explicit “caused” in the keyed option. **Remaining risk:** key alone describes an outcome; other choices describe prior events or announcements. Needs better outcome distractors before approval.

## B2 — 070 adequate

**Stem:** The emergency shelter was basic, but it provided adequate protection during the storm. Which report is consistent with that assessment?

| ID | Option |
|---|---|
| **A (key)** | “Everyone remained safe, although the building was uncomfortable.” |
| B | “The shelter had excellent facilities, but rain entered every room.” |
| C | “The building was comfortable, but it offered no protection from the wind.” |
| D | “The shelter was spacious, but several people were injured by falling debris.” |

**Improvement:** All options describe shelter quality, safety and trade-offs; not just 'enough' versus ridiculous extremes. **Remaining risk:** safety is an outcome proxy for adequacy and A could be true by luck. Reviewer must judge whether the inference is sufficiently supported.

## C1 — 044 nuanced

**Stem:** Which conclusion most carefully reflects the evidence that attendance improved overall but results varied between year groups?

| ID | Option |
|---|---|
| A | “The programme succeeded, so it should be expanded without changes.” |
| B | “The programme failed, since some year groups improved less than others.” |
| **C (key)** | “The overall gain is encouraging, though its impact differs by year group.” |
| D | “The results are mixed, so the programme has had no measurable effect.” |

**Improvement:** More plausible academic assessments, not simply one option with *but*. **Remaining risk:** keyed option still uniquely balances positive and qualified evidence; this may be inherent to the target construct. Assess whether it distinguishes C1 vocabulary from reading inference.

## B2 — 088 counterproductive

**Stem:** A school introduced extra homework reminders. Students began ignoring notifications, and more work was submitted late. Which description best fits the reminders?

| ID | Option |
|---|---|
| **A (key)** | “They had an effect opposite to the one intended.” |
| B | “They were useful at first but became less effective.” |
| C | “They had little effect on submission patterns.” |
| D | “They improved submission rates for some subjects only.” |

**Improvement:** Distractors now describe related degrees and patterns of effectiveness rather than random unrelated events. **Remaining risk:** the stem still supplies the full causal narrative, so a strong reader may infer the key without knowing *counterproductive*. Better test may use *counterproductive* in the stem and ask for a plausible contextual implication.

## Mandatory acceptance checks for each proposed revision

1. **Single-key test:** an independent reviewer must explain why each distractor is wrong and identify any plausible second key.
2. **Clue audit:** compare option length, register, formatting, absolutes, repeated stem vocabulary, grammatical fit and target-word echoes.
3. **Construct audit:** ask whether the student needs the target vocabulary knowledge, rather than common sense or generic reading inference.
4. **Level audit:** provisional A1–C1 classification must be separately reviewed against an explicit reference scale.
5. **Pilot evidence:** inspect option-selection rates, discrimination, response times and level-boundary performance before release.
6. **Release gate:** no silent overwriting of the live draft bank, no auto-approvals, and no enabling mandatory student lock until independently reviewed and piloted.

**Editorial verdict:** The eight replacements are a starting point, not eight finished questions. The warnings are intentional. Prioritise a better item *construct* over cosmetic distractor edits.
